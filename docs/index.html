MedRecon3D

面向临床交付的医学影像三维重建 + 多级配准 + 量化测量系统。
DICOM 序列进 → 分割、重建、配准、测量全部跑完 → 输出可打印 STL、可旋转三维模型、结构化测量报告、 以及一个能上传调用的 HTTP 服务。
CPU 与 GPU 两条链路都能跑，并做逐项数值一致性自检。

M1–M3 重建为何 GPU 没有收益

阶段CPUGPU
读取 DICOM0.60 s0.60 s
各向同性重采样0.51 s0.37 s
分割（阈值 + 连通域 + 孔洞填充）7.26 s7.25 s

总计26.75 s26.42 s

瓶颈在 CPU 侧的 Marching Cubes（18 s）与逐层孔洞填充（7 s）—— binary_fill_holes 是串行 flood fill，GPU 上要用迭代膨胀硬模拟，反而更慢。 所以这一段 GPU 化的部分只占约 1.5 s，收益不在这里，在 M4 配准。
