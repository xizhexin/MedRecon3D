# =============================================================================
# MedRecon3D · GPU 版依赖
# =============================================================================
# 基础依赖（numpy / SimpleITK / scikit-image / trimesh ...）见 requirements.txt，
# 这个文件只补 GPU 相关的部分。
#
# 不要直接 `pip install torch`，理由如下：
#
# 【1】必须挑对 CUDA 版本。
#     Pascal 架构的卡（TITAN Xp / GTX 1080Ti，sm_61）在 cu12x 的官方 wheel 里
#     没有 kernel，跑了就报：
#         CUDA error: no kernel image is available for execution on the device
#     而 `torch.cuda.is_available()` 在那种情况下**依然返回 True**，
#     要到真正做第一次运算才炸 —— 所以别指望它能帮你发现问题。
#     cu118 的 wheel 仍带 sm_61，Pascal 卡只能走这条线。
#
# 【2】torch 的 wheel 不含 CUDA 运行库，下面这一串 nvidia-* 是必须的，
#     否则 `import torch` 就报 `libcudart.so.11.0: cannot open shared object file`。
#
# 【3】这堆包加起来 1.7 GB，而 **pip 的下载器实测比 curl 慢 100 倍**
#     （同 URL：curl 16.4 MB/s vs pip 0.15 MB/s；799 MB 的 torch wheel 两次
#     卡在 64 MB 不动）。所以请用 tools/fetch_wheels.py 先下好，再离线安装：
#
#         python tools/fetch_wheels.py --dest /root/wheels \
#             nvidia-cuda-runtime-cu11==11.8.89 nvidia-cudnn-cu11==9.1.0.70 ...
#         pip install --no-index --find-links=/root/wheels \
#             torch-2.5.1+cu118-cp312-cp312-linux_x86_64.whl \
#             nvidia-cudnn-cu11==9.1.0.70 ...
#
#     或者直接跑 `bash setup_gpu_env.sh`，它把这些都串好了。
# =============================================================================

# --- torch 本体（Pascal 架构锁 cu118）---
# 从 https://mirrors.aliyun.com/pytorch-wheels/cu118/ 取：
#   torch-2.5.1+cu118-cp312-cp312-linux_x86_64.whl   (799 MB)
# 非 Pascal 卡（sm_70+）可以用更新的 cu12x，自行调整。
